# Quick Usage Guide

## Getting Started in 5 Steps

### 1️⃣ Open a Conversation
Navigate to ChatGPT, Grok, Gemini, or DeepSeek and open any conversation.

### 2️⃣ Find the Export Buttons
Look for three buttons in the platform header:
- **W** icon - Word Export
- **PDF** text - PDF Export
- **⚙** icon - Settings

The buttons appear automatically and integrate into the platform's native UI.

### 3️⃣ Configure Settings (Optional)
- Click the **Settings** button (⚙ icon) to open the settings panel
- Configure export options:
  - **Filename Format**: Custom filename pattern
  - **Document Title**: Override conversation title
  - **Page Margins**: normal, narrow, moderate, or wide
  - **Theme**: light or dark
  - **Page Orientation**: portrait or landscape
  - **Page Format**: A4, Letter, or Legal
  - **Enable Compression**: Reduce file size
- Click **Save Settings** when done

### 4️⃣ Select Export Format & Messages
- Click **Word** or **PDF** button to choose export format
- Checkboxes will appear next to each message
- Click messages to select/deselect them (they'll turn green)
- A banner shows your selection count
- A green **Export** button appears when messages are selected

### 5️⃣ Export
- Click the green **Export** button
- Your file will download automatically in the chosen format
- Filename follows your configured pattern with timestamp

## Button Interface

### Three Action Buttons

#### Word Button (W)
- Selects Word export format
- Enables selection mode when clicked
- Shows visual indicator when Word format is selected

#### PDF Button
- Selects PDF export format
- Enables selection mode when clicked
- Shows visual indicator when PDF format is selected

#### Settings Button (⚙)
- Opens/closes the settings side panel
- Configure all export options
- Settings persist across sessions using Chrome Storage Sync

### Dynamic Export Button
- Appears automatically when messages are selected
- Green background with download icon
- Exports in the currently selected format (Word or PDF)
- Disappears when no messages are selected

---

## Selection Tips

### Individual Selection
- Click any message to toggle its selection
- Selected messages turn green with a checkmark
- Click again to deselect

### Bulk Selection
- **Select All** (via popup) - Selects every message in the conversation
- **Clear All** (via popup) - Deselects all messages

### Export Without Selection
If you don't select any messages and click Export, you'll be prompted to export the entire conversation.

## Settings Panel

### Available Settings

#### Filename Format
- Pattern for exported filenames
- Default: Uses conversation title + timestamp
- Supports custom patterns

#### Document Title
- Override the conversation title in exports
- Useful for standardized naming

#### Page Margins
- **Normal**: Standard margins (1 inch / 2.54 cm)
- **Narrow**: Minimal margins
- **Moderate**: Balanced margins
- **Wide**: Large margins

#### Theme
- **Light**: Light background, dark text
- **Dark**: Dark background, light text
- Applies to both Word and PDF exports

#### Page Orientation
- **Portrait**: Vertical page layout
- **Landscape**: Horizontal page layout

#### Page Format
- **A4**: International standard (210 × 297 mm)
- **Letter**: US standard (8.5 × 11 inches)
- **Legal**: US legal (8.5 × 14 inches)

#### Enable Compression
- Reduces file size for large conversations
- Toggle on/off as needed

## Troubleshooting

### Buttons Not Appearing
1. Refresh the page
2. Check that you're on a conversation page
3. Look for console errors (F12)
4. Try disabling/re-enabling the extension

### Export Not Working
1. Make sure messages are selected
2. Check browser's download permissions
3. Try a different export format
4. Check console for error messages

### Settings Not Saving
1. Check Chrome storage permissions
2. Ensure sync is enabled in browser
3. Try reopening settings panel

### Format Issues in Exports
1. Verify settings are correct (margins, theme, etc.)
2. Try different page format or orientation
3. Check if conversation has special characters
