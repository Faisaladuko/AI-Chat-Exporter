## 🚦 Getting Started (Quick)

1. **Load Extension**
   ```
   Chrome → Extensions → Developer Mode → Load Unpacked
   Select this folder
   ```

2. **Test It**
   ```
   Go to ChatGPT → Open conversation
   Click extension → Enable Selection
   Select messages → Export
   ```

3. **Read Documentation**
   ```

   USAGE.md - Quick tips
   ```
